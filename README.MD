# Diplom_3 – UI-тесты на Stellar Burgers

Проект реализует UI-автотесты для сервиса [Stellar Burgers](https://stellarburgers.nomoreparties.site/) в рамках дипломного спринта.


# Используемые технологии
- Java 11
- JUnit 4
- Maven
- Selenium WebDriver
- Allure Report
- Page Object
- WebDriverManager
